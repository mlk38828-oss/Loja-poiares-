# Loja Poiares

Versão simples para publicar no GitHub Pages.

## Arquivos
- index.html
- style.css
- script.js

## Publicação
1. Crie um repositório público no GitHub.
2. Entre em **Add file → Upload files**.
3. Envie os 3 arquivos acima.
4. Faça **Commit changes**.
5. Vá em **Settings → Pages**.
6. Em Source, selecione **Deploy from a branch**.
7. Escolha `main` e `/ (root)`.
8. Salve.

Não renomeie `index.html`.
